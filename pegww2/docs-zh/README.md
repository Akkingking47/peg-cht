## 三、翻译口径（便于对照与复查）

1. **术语**：见 `_翻译须知与术语.md`（双轨制：军事名词用军语、游戏机制词用玩家词）。
   与**游戏内已交付文本**对齐，例：`Bridging`＝架桥 · `River Assault`＝强渡 · `Special Equipment`＝特种装备 ·
   `BV/V/TV`＝辉煌胜利/胜利/战术胜利 · `D&S`＝部署与补给。
2. **人名、文件名、地图 stem、URL、版本号一律保留拉丁原文**（不音译、不意译）。
3. **地名**首见作 `译名(原文)`，例 `卡昂(Caen)`；同段再现可只用中文。
4. **`SSI (地图名)`** 统一作 `SSI 原版：<译名>`。
5. **地图文件名 stem**（如 `Oakridge`、`wdnarv`）保留原文 —— 它们是文件引用，译了反而对不上。
6. **原文的缺陷照实保留**（作者笔误、断句、OCR 残留），**不擅自修正、不加译者注**。
   - 例外：若 `?` 夹在字母中间，那是 RTF 的 `\uN?` 兜底字符（如 `Weser?bung` 实为 `Weserübung`），按上下文还原。
