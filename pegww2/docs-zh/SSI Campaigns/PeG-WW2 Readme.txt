5 个 SSI 战役 3.0 版

这五个 PG2 SSI 战役在 2000 年由 Mark Kirby 转换用于 PeG-WW2。
请下载 PeG-WW2 的 SCENARIO 目录中的所有文件，由于文件名未作修改，它们会直接替换 1.0 版现有的文件。
无需下载地图，因为 PeG-WW2 安装程序已包含所有 SSI 地图。

对 Mark Kirby 战役转换版的改动：

* 我在 CAM 文件中加入了影片引用。  
使用了以下影片：NewGMWin, Medalgem, Gerloss, 1, 2, 3, Fas2, 4, Wdunkirk, Fas11, Fas9, Victory1940, Fas12, 5, 6, 7, Tobruk, 8, 9, 10, 11, 12, 13, 14, 15, Kursk, 18, 16, 17, Medalusm, Amerloss, 19, 20, Medalukm, Ukloss, 21, Sovbv, Medalrum, Rumloss, 22, Fas16, Sovend.
请在 Adlerkorps 网站下载 SMK 格式的影片：http://www.adlerkorps.com/
PeG-WW2 游戏说明文件说明了如何将 SMK 影片转换为 AVI 格式。  

* 战役介绍文本文件已作修改。  

* 与本战役包的 1.0 版相比，部分场景作了小幅改动，飞机的朝向已得到修正。

* 五个 XLS 文件现在显示各战役的路径：  
闪击战（德军战役）（27 个场景，最长路径为 18）
保卫帝国（德军战役）（6 个场景，最长路径为 6）
西线十字军（英军战役）（6 个场景，最长路径为 6）
西线十字军（美军战役）（6 个场景，最长路径为 6）
向柏林进军（苏军战役）（6 个场景，最长路径为 6）

* 我转换并加入了一个名为“Red Tide Rising”的 SSI 独立场景，描写 1945 年美军与苏军的对抗。该场景与 PG2 原版一样，不属于任何战役。

* SSI 闪击战与闪击战 REDUX 战役的附加内容：

目标：
位于海洋格上的地面单位不能移动到陆地格上。
因此，“Malta”与“Savannah”场景（在两个德军战役中）已得到改进，现在可以借助运输船（具备“HQ”即部署能力）把单位正确部署到陆地格上。


说明：
1. 在游戏中先点击退出部署按钮，再点击部署按钮，以便通过运输船部署单位（已部署的单位可以移动，从而腾出空间部署新单位）；
2. 你不必一次部署所有单位，只要运输船还存在且与陆地格相邻，就可以继续部署单位。
