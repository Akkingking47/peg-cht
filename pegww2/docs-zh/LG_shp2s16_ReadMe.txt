这是一个 Windows 程序，可方便地把 SHP 文件转换成 S16 peoples 格式
因为它会转换文件夹中找到的所有 SHP 文件。  

因此你可以转换图片地图文件或图标文件，随你需要。

它是一个外壳工具，所有工作都由 Fred Chlanda 的工具完成。

安装时，只需把可执行文件解压到你喜欢的任意位置，这就是
所需的全部安装。建议最低屏幕分辨率为 800x600。  

和往常一样，它用注册表来「记住」你上次的设置。

使用方法：

1) 把你想要转换的所有 SHP 文件放到一个临时文件夹中，然后运行该工具。

2) 选中你用过的那个文件夹，你会看到你复制过去的所有文件。

3) 如果没有在选中的文件夹里找到 Fred 的工具和调色板，程序会提示你，此时你只能 
      生成 BAT 文件但无法完成转换。

4) 按「查找 Fred 的工具」和「查找 PG2 调色板」按钮来定位它们的位置。

5) 当它询问是否复制到选中的文件夹时，回答「是」（或手动复制）

6) 可选：设置转换完成后是否删除 SHP 文件（默认不勾选）

7) 还提供「仅生成 BAT 文件」单选项，用于你暂不想转换、
      或想先看看会做些什么的情况。
      默认选中第二项。无论哪种情况，只要按「确定」就会生成 BAT 文件。

就这么简单。
