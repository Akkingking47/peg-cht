***欢迎来到非洲，将军！***

祝贺你被任命为我们非洲远征军的新任总司令。你的任务是在我们的盟军经历了一年失败之后，协助我们的意大利伙伴对抗英军。

意大利人在非洲已经失去了大部分领土，我们不能允许英国人取得整个大陆的控制权，否则地中海将完全落入敌人的掌控。

OKH 知道你有能力阻止敌人，粉碎他的计划。为此，我们将把第15装甲师和第5轻装师交给你指挥，不过，随着你的战果，会有更多补充兵员派给你。

一旦你抵达非洲，你就会感觉到这里的环境与迄今为止你作战过的波兰或法国土地完全不同。那里的地形是沙漠，白天酷热，夜晚冰冷。道路主要是卡车车轮在沙丘之间碾出的沙带。燃料和水都是珍贵的物资，基本上，北非沙漠里的生活很艰苦。 

另一方面，敌方部队主要由英国第8集团军的部队组成。其中一些敌方单位是英军中最精锐的，例如第7装甲师（沙漠之鼠）。英军的人数肯定超过我们的单位，但我们的装备更好，至少我们是这样认为的。

***引言***

本战役如实展现了德意志非洲军团在北非的全部行动，从 Rommel 抵达 Tripoli 起，直到 El Alamein 的战役。它也展现了战役中的沙漠条件、补给短缺与燃料短缺。我们无法补充单位损失的全部兵员，而敌方空军拥有完全的空中优势……基本上，沙漠中的条件很艰苦。

你将自1941年一直战斗到 El Alamein 的重要战役。在那之后……只有你知道德意志非洲军团会去向何方。

***安装***

将文件 English_Campaign.zip 解压到你的主场景文件夹，通常是 c:\panzer2\scenario，然后把文件 Efile_LG.zip 解压到 Panzer General 2 主文件夹，通常是 c:\panzer2。本战役使用的 LG 装备文件版本是 1.4，也就是随战役附带的版本。

 	 \tPG2 2.0 补丁。装备文件超过 2000 个单位时需要这个补丁。该补丁可在 http://es.geocities.com/latingenerals/ 的“downloads y tutoriales”栏目中找到，你也可以在这里找到；http://go.to/panzergeneral2 。
