## 工具修正（本轮实测后改）

| # | 问题 | 修法 |
|---|---|---|
| T1 | **保护串清单过宽**：裸词 `NAMES` 把散文里的 "names" 也保护了 ⇒ 译者正常译成「名称」反被误判"保护串丢失" | 去掉裸词，只保留**带扩展名的文件名/路径/URL/版本号/明确程序名**；并**把保护串清单写进 `_src` 第 4 列**，回写以它为准（不再重算），避免改规则导致旧译文占位符错位 |

| T4 | RTF 超链接域 `{\field{\*\fldinst HYPERLINK "http://…"}}` 的 URL 会被当正文译 | 屏蔽 `\fldinst` 组 + 含 `HYPERLINK/PAGEREF/…` 的段 |
| T5 | RTF 段内**换行**会撑破 TSV | 段内换行/制表折叠为单空格（RTF 空白不参与排版） |
| T6 | RTF `verify` 用"按位置比对控制字"⇒ 插字体条目后全部误报漂移 | 改**结构化比较**：控制字计数（排除自插项）+ 花括号总数 + 未译文本逐字节 |
| T7 | CJK 字体条目插错位置（落进第一个字体条目内） | 用**平衡花括号**定位 `{\fonttbl…}` 组末尾；并处理「控制字后紧跟 `{` 只算 1 层」 |


## 技术决定（留痕）

1. **TXT 出稿 = UTF-8 with BOM**（Windows 记事本/写字板直接可读；原件零改动，译文另存）。
   实测：BOM 只写在第 0 段；用 `utf-8-sig` 读即还原原文逐行。
2. **RTF 出稿 = latin-1 回写 + `\uN?` 兼容**：把 CJK 字体条目 `{\fCJK\fnil\fcharset134 SimSun;}`
   追加到 `{\fonttbl…}` 组**内末尾**，并在每段译文前插 `\fCJK`（否则默认字体无中文字形）。
   ⚠️ 坑：RTF 的 `{\fonttbl{…}}` 组深度计算要**把「控制字后紧跟的 `{`」只算 1 层**，否则插入点会落进第一个字体条目内部。
3. **保护串**在 TXT 抽取阶段替换为 `\x01N\x02` 占位符，回写时还原 ⇒ 保证逐字符不变（G3）。
4. **RTF 段 = 「两个控制字之间的裸文本」**，段内首尾空白按 `strip()` 处理（RTF 中控制字后的换行不显示）。

| # | 问题 | 修法 / 教训 |

| T8 | **`{\*\…}` 可忽略目标组**（Word SmartTag/factoid 元数据）里的词（`PlaceType`/`place`/`PlaceName`）被当正文译了 | **按字节区间**屏蔽 `{\*…}`（`star_spans()`）。⚠️ 一开始我改了**词法**去识别 `\*`，那会**改变段号空间**⇒毁掉既有译稿（同 W21 教训）——**段号是抽取↔回写的键约定，绝不能变**，故改为不动词法的区间屏蔽 |
