# DOCS 汉化 · 翻译须知与术语对照（子代理必读）

> 适用于《PeG-WW2》（People's General 二战 MOD）面向玩家文档的汉化。
> 目的：**同一术语全场一致**，并与已交付的游戏内文本对齐。

## 一、绝对规则

1. **保护串原样保留**（不译、不改大小写、不拆开）：
   - 文件名/扩展名：`WW2GUI.TXT` `WW2-EQP.EQP` `START.S16` `MODGEN.DAT` `WW2-027b.EXE` …
   - 路径：`SCENARIO\` `USERSCEN\` `D:\…\` …
   - URL、邮箱、版本号（`2.7c`、`1.02d`）、工具名（`PeG Suite`）
   - 人名：`Redball` `Mark Kirby` `Robert Mary` `Luis Guzman` `Fred Chlanda` `John McNulty` `Jorge Gabitto`
   - 游戏/厂牌名：`People's General` `PeG-WW2` `SSI` `Panzer General II` `PG2`
2. **格式符原样**：RTF 抽取表里的占位符 `\x01N\x02`、TXT 表里的 `\t`（制表符）必须原位置保留。
3. **不增不删**：段落数、行号与原文一一对应。
4. **不加戏**：不添加原文没有的解释、不写"译者注"、不扩写。

## 二、文风

- **平实的技术说明文**（面向玩家，不是文学翻译）。不要文言腔、不要四字堆砌、不要"之乎者也"。
- 原文啰嗦就照实啰嗦；原文是清单就译成清单。
- 全角标点：句号「。」逗号「，」顿号「、」引号「"」；**括号内夹注原文用半角圆括号**，例：`卡昂(Caen)`。
- 数字/编号保留阿拉伯数字；`1)` `2)` 保留原样。

## 四、已定专名（照用，勿另造）

- 部队/兵器型号保留拉丁原文：`Pz 35(t)`、`sIG33 38(t)M`、`8.8cm FlaK36`、`Ju-87B`、`P-51D`
- 装备括注简写：载具＝`（SdKfz 251/1）`（**不要**写「半履带车运载」）
- 地名首见译法：`译名(原文)`，例 `卡昂(Caen)`；同段再现可只用中文

## 五、交付自检（提交前逐条过）

1. 段数/行号与原文一致？
2. 每个保护串都在、且逐字符未变？
3. 占位符 `\x01N\x02` 与 `\t` 位置正确？
4. 有没有整段还留着英文？（专名/型号/URL 除外）
5. 术语是否与上表一致？
