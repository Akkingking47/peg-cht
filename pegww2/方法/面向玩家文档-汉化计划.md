## 二、技术路线

### 2.1 核心原则：**保护标记（markup-safe）**

游戏文本那套"整行查表"**不适用于文档** —— 文档里混着排版标记、超链接域、表格、文件名、路径。
本计划的铁律：

1. **只译自然语言段**；下列一律**原样保留**：
   `\* HYPERLINK …` 域 · `\par` 等控制字 · 表格边框 · 图片引用 ·
   **文件名/路径/扩展名**（`EQUIP97.TQP` · `LAH_v1.zip` · `*.scn` · `SCENARIO\`）·
   **键位/按钮名**（与 `WW2Gui.txt` 既有译法对齐，如 `D&S`→「部署与补给」）·
   版本号 · 作者名 · URL
2. **术语一致性**：单位/兵器/地名一律**查已有真源**（`ww2-scn-map.tsv` 21,865 条 + `ww2-eqp-map.tsv` + `peg\research\ui-glossary.tsv`），
   **不另造译名**。这是本作最大的资产 —— 场景层已把绝大多数军事专名定死。
3. **格式保真**：RTF 保留原控制字与结构；TXT 保留换行风格；XLS 只译文字格、公式与路径不动。

### 2.2 管线（与现有项目习惯一致）

```
① 抽取   extract_docs.py   →  docs-zh\_src\<相对路径>.tsv
                            列：段号 \t 英文原文 \t 标记保护占位
② 翻译   子代理/人工填      →  docs-zh\_fill\<相对路径>.tsv（只填译文列）
③ 回写   build_docs.py     →  docs-zh\<相对路径>（先重建到临时 → 回读校验 → 才写正式）
④ 校验   verify_docs.py    →  逐文件：段数一致 / 标记完整 / 保护串逐字节未变 / 无残留整段英文
```

- 脚本落 `work\pegww2\docs\`
- **默认 dry-run**，`--apply` 才写；写前备份到 `pegww2\testbed\backup\docs\`
- 子代理**串行 + 小片**（≤600 段/片，沿用场景层血泪纪律 W13：绝不并发多个重负载子代理）

## 三、风险与对策

| 风险 | 对策 |
|---|---|
| RTF 控制字被误译/误删导致**文档打不开** | G2 逐文件结构比对；先在临时重建、回读校验，才写正式 |
| 表格/路径被改坏（如 `EQUIP97.TQP`） | G3 逐字节保护串校验；抽取阶段就把保护串换成占位符，回写时还原 |
| 术语与游戏内不一致（玩家对不上） | 强制查真源；G4 抽查；新术语回写 `docs-zh\_术语新增.tsv` 待你批 |
| 文档体量大、易半途而废 | 按 D1→D5 分批，**每批独立可交付**，D1 完成即可先用 |
| 版权 | 仅个人研究、不发布（工作区既定）；**不碰 SSI 官方手册影印件** |
