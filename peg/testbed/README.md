## 二、操作步骤

```bash
cd <本仓库克隆目录>
PY=python        # 你自己的 Python 3；或先 `call env.cmd` 注入 PY

$PY peg/testbed/gui030-trial.py deploy     # ① 部署（先自动校验备份 md5）
#  ② 手动启动 %PEG_GAME%\PeG030.exe（按下面「看哪一屏」观察）
$PY peg/testbed/gui030-trial.py restore    # ③ 看完立刻还原
```

`verify` 可随时查现网/备份/试点三者状态与 md5。

## 三、看哪一屏（请按此顺序观察并回报）

**屏 A · 主游戏画面底部按钮栏**（最直接）
- 启动 → 载入任一场景 → 看屏幕**下方/侧边的按钮条**。
- 找这几处：`下一单位`（Next Unit）· `结束回合`（End Turn）· `补给`（Supply）· `档案`（Dossier）·
  `购买单位`（Requisition Unit）· `检视部队`（Inspect Unit）。
- **要看**：① 是否显示为中文（应当显示）；② 有没有**半个字/方块/问号**；③ 有没有被按钮边框**切掉**。

**屏 B · 游戏功能菜单**
- 点 `游戏功能`（Game Functions）→ 找 `全屏`（Full Screen）· `退出游戏`（Exit Game）。

**屏 C · 国家/阵营显示**
- 任一处显示国家名的地方（场景信息、部队资料、国家选择对话框）看 `中国`（China）位置。

**屏 D · 胜利分级**（若有触发条件）
- `大胜`（Brilliant Victory）—— 一般出现在战后结算；不触发也没关系，跳过。
