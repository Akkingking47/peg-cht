# PeG 中文化术语口径：军事感 × 玩家可读性 的平衡（双轨制）

> 2026-10-10 制定。起因：用户反馈「有些词条有点过了」，要求参考同类军事游戏
> （**《装甲军团》Panzer Corps / 《装甲将军》Panzer General 系**）如何平衡军事感与普通玩家。

## 一、参照对象与结论

| 参照 | 性质 | 可读到的术语事实 |
|---|---|---|
| **《装甲军团2》官方中文手册** | Slitherine/Matrix 官方中文本 | `威望点数`(Prestige) · `核心栏位`(Core slots) · `碾压`(Overrun) · `压制`(Suppression) · `工事`(Entrenchment) · `补充人员/补充`(Replacements) · `新兵/老兵补充` · `精锐更换` · `撤销次数` · `战争迷雾` · `控制区` · `战损` · `转场` · `拆分` |
| **《装甲军团2》中文攻略**（游民/3DM 等） | 玩家通行读法 | `威望点`·`补充`·`回血`·`拆分`·`据点`·`包围圈`·`老练等级` |
| **《装甲将军》原版机制说明** | 系列正统源头 | `prestige` 的社区译法＝**威望**；`normal replacements`／`elite replacements` |
| **OpenPG `strings-zh.txt`** | **同引擎前作、已交付锁定** | `补充兵员`·`战地司令部`·`查看部队`·`决定性胜利`·`声望`（注：与 PC2 的「威望」不同源） |

**⇒ 《装甲军团》的处理方式＝「双轨制」：军事名词用军语，游戏机制词用玩家词。**

## 二、双轨制口径（PeG 采用）

### A 轨 · 军语保留（专业度来源）
**适用**：兵种 / 编制 / 装备 / 战斗数值 / 战术效果 / 战场要素

- 例：`坦克·反坦克·炮兵·驱逐舰·战列舰·潜艇·航空母舰`｜`工事·压制·碾压·侦察·渡河突击`
- 保留缩写：`ZOC·LOS·LOF·AT·FlaK·BB·ASW`
- 保留型号：`M4A1·M2A3 Bradley`
- **判据**：军事游戏玩家认得（读过 PG/PC/《钢铁雄心》即无障碍）

### B 轨 · 玩家可读（去掉「过了」的部分）
**适用**：菜单 / 按钮 / 游戏机制资源 / 技能名 / 战斗提示

三条红线：
1. **不给游戏机制起军语名**
   `Prestige` → **威望**（不是「资历」）｜`Replacements` → **补充**｜`Overstrength` → **超编**
2. **不用生僻军语缩略，改通行说法**
   `Interdiction` → **空中封锁**（不用「遮断」）
   `Counter-Battery` → **炮火压制**（不用「反炮兵」）
   `Indirect Defense` → **远程防御**（不用「间接防御」，且对齐 OpenPG）
   `Wild Weasel` → **防空压制**（不直译「野鼬鼠」）
3. **技能/特性用形象短词**，不打官腔
   `Shoot and Scoot` → **打了就跑**（不用「快打快撤」）
   `Blitzer` → **闪电战**｜`Ground Taker` → **攻坚专家**｜`Ambusher` → **伏击者**
   `Tunnel Rats` → **坑道兵**｜`Forward Observer` → **炮兵观察员**

### ⭐ 数值标签命名法：**用「具名目标类型」，不用含糊形容词**

反例 → 正例：

| 原文 | ❌ 形容词式 | ✅ 具名目标式 |
|---|---|---|
| Hard Attack | 对硬攻击 | **对装甲攻击** |
| Soft Attack | 对软攻击 | **对人员攻击** |

依据：**《钢铁雄心4》官方中文**用 `对装甲杀伤 / 对人员杀伤`。
理由：① `硬/软` 是形容词，后面缺名词，中文不成立；② 具名后与同组
`对空攻击 / 对直升机攻击 / 对地防御` **句式完全统一**；③ 直指含义（硬=装甲目标、软=无装甲目标），
玩家不必先学「硬/软」的行话。

> 注：**目标类型**（`Soft Target / Hard Target`，行 71/72）目前仍是 `软目标 / 硬目标`。
> 若要与此处彻底对齐，可改为 `装甲目标 / 人员目标`（待定）。

### ⭐ 查证：「Hard/Soft Attack」到底有没有标准军语？

**分两层，结论不同 —— 这一点必须说清。**

| 层面 | 是否有标准军语 | 依据 |
|---|---|---|
| **`Hard Target` / `Soft Target`** | ✅ **有，且是国军标正式术语** | **GJB 1365-92《核火力运用的术语与符号》**：**硬目标**＝「具有较强抗力，不易摧毁的目标」；**软目标**＝「具有较小抗力，易于摧毁的目标」。亦见《核打击目标》军语条目（按抗超压能力分类） |
| **`Hard Attack` / `Soft Attack`** | ❌ **没有** —— 真实军事条令中不存在此术语 | 它是**兵棋机制词**，指「单位攻击某类目标时的强度值」。英文侧也是游戏造词 |

**⇒ 因此「军语化」的正确做法是：用军语词根 `硬目标/软目标` + 机制后缀**
⇒ **`硬目标攻击` / `软目标攻击`**（或完整式「对硬目标攻击力」）

> ⭐ 佐证：工作区术语总库中本系列**已锁定**过该译法 ——
> `Hard Attack → 硬目标攻击`、`Soft Attack → 软目标攻击`、`Hard target → 硬目标`、`Soft target → 软目标`
> （来源 `EFILE_NASHORNPBEM`，状态 LOCKED，HIGH 置信）

#### ⚠️ 语义偏差提示（选型时必须知道）

军语「硬目标」偏重**抗毁能力**（加固机堡、地下设施、装甲工事），
而 PeG/HOI 的 `Hard Target` **特指装甲单位**（坦克等），**不含加固工事**。
⇒ 二者是**包含关系**：军语「硬目标」⊃ 游戏的 hard target。用「硬目标」属借用，不算错，但范围略宽。

#### 三条路线对照（供决策）

| 路线 | 译法 | 军语符合度 | 玩家可读性 | 与游戏内 行71/72 一致 |
|---|---|---|---|---|
| **A 军语最正** | **硬目标攻击 / 软目标攻击** | ★★★ 有 GJB 定义 ＋ 前作已 LOCKED | ★★ 需懂「硬/软」 | ★★★ 完全一致 |
| **B 具名（当前采用）** | 对装甲攻击 / 对人员攻击 | ★ 军语无此组合，但语义准确 | ★★★ | ★ 不一致 |
| **C HOI4 官译** | 对装甲杀伤 / 对人员杀伤 | ★ | ★★★ | ★ |

#### ✅ 最终决定（2026-10-10）：**A 路线 ＋ 量度词**

```
Hard Attack       → 硬目标杀伤      Soft Attack      → 软目标杀伤
Air Attack        → 对空杀伤        Helicopter Attack→ 对直升机杀伤
Close Attack      → 近距杀伤        （防御侧不变：对地防御/对空防御/近距防御/远程防御）
目标类型          → 硬目标 / 软目标 / 高空目标 / 直升机舰船目标（本来已对齐）
misc030 状态栏    → Attk: 杀伤: ／ Dfnd: 防御:
```

**两条理由叠加**：
1. **A 路线的军语正当性** —— 硬目标/软目标 有 **GJB 1365-92** 定义，且本系列前作已 LOCKED 过
2. **量度词原则** —— 这些词位于**部队属性面板**，是**数值**不是动作。
   `攻击` 是动词性词，放数值栏易被误读成按钮/动作；**`杀伤` 是量度词，天然是「能力值」**。
   《钢铁雄心4》官方中文即用 `对人员杀伤 / 对装甲杀伤`。

⚠️ **但动作/提示语仍用「攻击」**：`攻击中止！`(Attack Broken Off!) · `攻击中`(Attacking) · `突击中`(Assaulting)
—— 它们是**动作**，不是数值。**判据：这一项显示的是「一个数字」还是「一件事」？**

⚠️ 命名规则：**目标类名词直接接（硬目标杀伤），非目标词加「对」（对空杀伤、对直升机杀伤）。**

### 长度预算
UI 短标签 **≤5 汉字**（实测 4~5 字可完整显示，见 `docs\38` §6.5/6.9）。
