  - UI 文案在 exe 内是 **UTF-16LE 宽字符串**，集中于 `.rdata`（VA 7F000 / 文件偏移 0x7E200 / RawSize 115200）；按 ASCII 搜索全部 0 命中。

  - 字符串紧凑排列，串间仅 `\x00\x00`，**余量只有 2–8 字节** → 铁律：**译文字符数 ≤ 原文字符数**（中文按 UTF-16 计通常与英文等长或更短，故可原地替换、绝不溢出）。
  - 只改 `.rdata` 数据字节、不动代码与指针 → **不受 ASLR/.reloc 影响**。

### POC：中文渲染可行（关键突破）
- **编码定案：UTF-8 with BOM**。裸 UTF-8（无 BOM）会被按单字节解析 → 中文全变 `?`。
