## 一、位图文字层：**成功**（已在实际安装文件中验证）

`decode_cwgen.py` 是本目录自带的只读解析器（纯 stdlib）：直接读两个安装目录的 `CWGEN.dat`，
按容器头 → 目录表 → 图标记录 → RLE 解码，导出 `HEX.S16[0]`。

| 文件 | md5 | 解出的荣誉榜 |
|---|---|---|
| `D:\Program Files\PeG\CWGEN.dat`（当前正式版） | `EB203C119C9D45E61CD2D7492A14D06E` | [`honor-official.png`](honor-official.png) = **英文原版**（HONOR ROLL／GENERAL／COLONEL／CAPTAIN，每组两行） |
| `D:\Program Files\PeG-1\CWGEN.dat`（分支版） | `99876F170A0EBDB9B4BAB93DA47FAA6E` | [`honor-branch.png`](honor-branch.png) = **中文版**（荣誉榜／上将／上校／上尉，三组**收成单行**） |

两者结构完全一致（800×600，`comp=1`，`nbytes=51441`，解码 480000 像素，**字节流恰好耗尽**）；
只有配色数不同：原版 71 色 → 中文版 **61 色**（中文笔画更省色阶）。

**独立复核的两条硬结论**：
1. 两个 `CWGEN.dat` 的**全部差异 36760 字节，100% 落在 `HEX.S16[0]` 区间内** ⇒ 其余 3366 个图形逐字节未动；
2. 解出来的图**就是中文荣誉榜** ⇒ 这一层是**真跑通的成果，不是计划稿**。
