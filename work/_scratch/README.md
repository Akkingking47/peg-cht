# `work\_scratch\` —— 一次性脚本存档区

> **性质**：**只读存档**。这里放的脚本是「跑过一次就再没人引用」的一次性审计 / 迁移 / 探针脚本，
> 由 **C-1「脚本生命周期治理」** 用 `git mv` 从 `work\` 各子目录迁入（**保留原相对路径**，也保留 git 历史）。
> 索引见 [`..\SCRIPTS.md`](../SCRIPTS.md) §2。

## 硬规则

1. **里面的脚本不得被活跃流水线引用。**
   禁止 `import`、禁止 `subprocess` / `Popen` 调用、禁止写进 `*.cmd` / `*.ps1` / 回归门禁 / 生成链。
2. **只进不出**：新增一次性脚本请直接落在本目录（可按项目建子目录），并到 `..\SCRIPTS.md` §2 登记一行。
3. **要复活就先搬回去**：某个脚本重新变成流水线一环时，用
   `git mv work\_scratch\<原相对路径> work\<原相对路径>` 搬回原位，
   并同步更新 `..\SCRIPTS.md` 的 §1 / §2。
4. **禁止删除**：本目录是历史证据（谁跑过什么、当时的口径是什么）。清理要单独走流程。
5. **判据可复核**：进入本目录的前提是「全工作区按文件名搜索 0 命中」，
   取证脚本与结果在 `work\out\_c1_scan_refs.py` / `_c1_zero_verify.txt` / `_c1_notmoved_refs.txt`。
