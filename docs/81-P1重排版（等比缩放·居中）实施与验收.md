## 1. 坐标模型（唯一权威定义）

```
s    = H/600              (S2 高度优先，16:9 玩法默认)
     = min(W/800, H/600)  (S1 等比)
X(x) = W/2 + (x − 400)·s        Y(y) = H/2 + (y − 300)·s      # center：屏幕中心是不动点
Xr(x)= W − (800 − x)·s                                        # right：到右边缘的间距按 s 缩放
Xs(x)= x·s                                                    # scale：锚定设计原点
Xt(x)= x·W/800                                                # stretch：横跨整屏
```
取整 round-half-up；**相邻共边用同一 mode ⇒ 自动同取整，不会出现 1px 缝**；命中测试与重绘登记复用同一变换。
代码：`work\peg\relayout\layout_model.py`（含 6 档分辨率固定断言，`python layout_model.py` 自检）。

1920×1080 实算（S2）：`s=1.8`，UI 盒 **1440×1080 居中**于 (240,0)–(1680,1080)，两侧各 240 px 留给地图。

## 3. P1 本轮做了什么

**只动数据面**：把 **0x4A96E8 控件矩形表**（记录 15 字节，前 8 字节 = 4 个 int16 矩形 `x1,y1,x2,y2`）按上面的 `center` 规则整体重排：

- 271 条有效记录 × 4 字段 = **1076 条内存站点**（第 271 号记录字段越界，整条跳过 ⇒ 共 272 条记录判定，1 条丢弃）；
- 例：`ctrl[0].x1 0 -> 240`、`ctrl[23].x1 127 -> 469`、`ctrl[135].x2 646 -> 1403`；
- 落地方式：沿用 `work\peg\peg_launcher.py` 的"挂起启动 → 全量校验 → 写入 → 回读一致 → 恢复运行"，**母本 exe 一字节不改**（md5 `c462e897b3aa1c384870c857ce9e01df`）；
- 新增开关：`--relayout`（默认关）、`--relayout-strategy S1|S2`；打开时**自动关闭会冲突的旧补丁**：I 组（同表 37 条"右对齐 +1120 平推"）与 K 组（dx/dy 平推），因为它们与新模型对同一批字节给出不同目标值；
- 实测：`--selftest` 输出 **"✅ 内存补丁完成：1277 条已写入并回读一致（exe 文件未改动）"**（275 − 74(I) + 1076 = 1277）。

**没动的**：M 组（地图面 4096 上限）、N 组（横向滚动钳位）、画布/视口（G/A/F/CODE_EDITS/H/D）、以及 800/600 的屏幕尺寸描述符（语义未证实，P1 故意不碰，避免把 stride/尺寸字段写坏）。
