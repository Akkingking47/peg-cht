## 五、写入过程中新发现并修补的坑

1. **`apply_residual.py` 底部无保护的 `main()`** —— 被 `import parse` 时执行，若外层带 `--apply` 会**连带触发误写**。已加 `if __name__ == "__main__":`。
2. **`tee | head` 触发 SIGPIPE 截断输出文件** —— 一度让 `out/place-txt-match.txt` 尾部残缺，误以为清单不完整。重跑不加 `head` 即恢复。
3. **新值「无汉字」守卫缺失** —— 写入后残留审计里「含汉字 13,910 → 13,909」「疑似漏译 388 → 389」这一对**联动信号**暴露了那 1 处倒退；据此新增 D 规则并回退。
4. **备份 shell 循环被 SIGTERM 中断** —— 161/170 时中止（源文件未受影响），改用 Python `shutil.copy2` 补齐并全量 md5 校验。
