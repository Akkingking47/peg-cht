### 修改流程（重要）

**不要直接编辑 `strings-zh.txt`**（GBK 易乱码，且会破坏行结构）。正确做法：

1. 编辑 `work\map1.tsv` ~ `map4.tsv` 中对应行号的译文
2. 运行：
   ```powershell
   & 'D:\DSH\军事游戏汉化\work\build-zh.ps1' -Deploy
   ```
3. 脚本会自动：按行号替换 → 校验行号/注释/空行 → 转 GBK → 结构自检 → 部署（并备份上一版为 `.bak`）

## 五、已知盲区（无法汉化的部分）

即使语言正确切换，**以下内容仍会显示英文**，这是引擎的硬编码限制（官方文档 "can be translated **up to a point**"）：

1. **程序级对话框**：如退出确认框 `Do you really want to exit ? ...`
   （注：该串虽在模板第 705 行且已翻译，但引擎实际未使用文件版本）
2. **战役浏览器窗口**：`Welcome to Open General`、`Filter campaigns having`、`TUTORIAL`、表头 `Title/Country/Equipment/Author/Period/Year` 等 —— 这些串在模板 916 行中**根本不存在**
3. **efile 数据内容**：efile 名称、描述（来自 `efile.xml`）、战役名（来自 `Campaigns.csv`）

> 上述第 1、2 项属于引擎内置文本，除非修改 exe 否则无法汉化。需在交付说明中告知玩家。

## 六、技术要点回顾（供后续阶段复用）

1. **语言开关**：`Settings.cfg` 的 `UI_Lang` 存**文件名基名**，正确值是 `strings-zh`（**不是** `zh`）
2. **切换方式**：必须在游戏内 **User Settings → Select UI Language** 下拉框中选择；直接改配置文件在旧值格式下会静默回退英文
3. **编码链路**：GBK 文件 → `MultiByteToWideChar(CP_ACP=936)` → UTF-16 → `TTF_RenderUNICODE` → FreeType
4. **字体**：`FONTS\Deng.ttf`（等线，单体 TTF）；引擎只导入 `TTF_OpenFont`，**不支持 `.ttc`**
5. **字号**：`SzFont1=SzFont2=12`，中文可读性良好，无需放大
6. **efile 级文本**：可放 `TEXT-ZH\` 子目录（含 `TEXT-ZH\SCENARIO\`），引擎优先从这里加载
