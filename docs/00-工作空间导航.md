交付单位＝**一个 efile**。全库 **21 个 `EFILE_*`**。

### 读表必读的四条注

   cp1252 高字节解成**假汉字**（`Pr鋞or` / `Compa耥a`=Compañía / `H鲻r`）而误算成已译；
   `verify` 曾被这类乱码骗过（见 `MECHANICS.md` §13）。

   `Intro for XXX` + `* Intro text *` 占位 —— 均无需译。**AO/Clu/PzLIGA 的 501 B 全 NUL 空壳
   不能用 `strip()` 判（去不掉 NUL）**，否则会误算成有正文。
4. **`.txt` 两处判据已于 2026-09-29 修正（见 `MECHANICS.md` §21）**：

## 五、改译文的正确流程

**不要直接改部署文件**（GBK 易乱码、易破坏行结构）。

| 对象 | 入口 | 命令 |
|---|---|---|
| L1 UI 主串 | `work\map1~4.tsv`（行号\|译文） | `& 'D:\DSH\军事游戏汉化\work\build-zh.ps1' -Deploy` |
| `.xscn` 场景数据 | `work\xscn\xscn.py` | `python work\xscn\xscn.py --efile <EF> verify\|export\|apply --map F\|zhfix --sub A B\|rawfix --map F`（后四者默认**干跑**，`--apply` 才写） |
| exe 硬编码串 | `work\exe\*_patch.py`（幂等） | 二次修正用 `exe_zhfix.py`（补丁脚本按英文匹配，汉化后必 0 命中） |
| AG 场景散文 | `work\ag-scenario\deploy.py` | `python deploy.py [--apply] [--only <前缀>]` |

> `.xscn` 工具的四个坑：① `cnt==0` 是**合法空组**不是结束；② key 必须统一 `strip()`；
> ③ 词典必须允许**空译文**；④ **`rawfix` 是修「保留原文」cp1252 残留的唯一入口**
> （`apply`/`zhfix` 都够不到 —— 它们被假汉字骗过）。

**cp1252 残槽批次的标准流程**（10-09 建，ATOMIC + COMWW2 实证）：

```powershell
python work\xscn\list_residual.py --efile <EF> --title   # 与 progress.py 同判据列出残槽 → work\<tag>\residual.tsv
python work\xscn\lookup_residual.py --efile <EF>         # 先查既有译法（label-keep/译名库/总库/跨efile词典）
python work\xscn\union_residual.py <EF> <EF2>            # 多 efile 合并去重（同名地名跨 efile 必须同译）→ 分块
# 子代理按 work\xscn\RESIDUAL-PLACE-POLICY.md 逐块译 → work\xscn\residual-zh\part-NN.tsv
python work\xscn\build_rawfix.py                         # 严校验（行数/原文列/拉丁/GBK/结构符号）→ 两表
python work\xscn\xscn.py --efile <EF> rawfix --map work\<tag>\<tag>-xscn-rawfix.tsv [--apply]
```

> ⚠️ **三个新坑**：① 映射表**必须丢弃 `dst==src` 的口径保留行** —— `rawfix` 会对它 `encode('gbk')`
> 而乱码串（`Ð#ð#P$à$`）装不下 GBK，**整个批次会崩**；② 译文允许保留的拉丁**必须出自原文**
> （`[RAF]`、`MAAF/12.ASC` 是既定保留），校验按「dst 的每段拉丁 ⊆ src」判；③ 结构符号数
> （`/ [ ] ( )`）逐条对拍，**例外必须显式登记理由**（见 `build_rawfix.py::STRUCT_EXC`）。

## 六、硬约束（违反必出问题）

1. 出稿 **GBK(936) + 无 BOM + CRLF**；工作稿用 UTF-8
2. `Settings.cfg` 的 `UI_Lang=strings-zh`（**不是** `zh`，写错静默回退英文）
3. 字体必须 **`FONTS\simhei.ttf`，禁用 `deng.ttf`** —— DengXian 在 12px 下拉丁字形溢出 advance，
   字符重叠（`Main` 渲染成 `Nlain`）。宋/黑/楷/仿宋的 ASCII 是**半角 6px**（＝汉字一半），天然吻合。
   换字体前**必须验证汉字覆盖**（`simsunb.ttf` 是扩展字体，全方块）
4. `strings-zh.txt` 必须与模板**逐行对应**，错行 = UI 整体串位
5. 含中文路径的 `.ps1` 必须存为 **UTF-8 with BOM**（PS 5.1 否则按 GBK 误读路径）
6. **禁止覆盖式改原文**；备份与覆盖分两条独立命令；**先重建到临时 → 回读校验 → 才写正式**
7. 需要截图时**必须停下**，由用户手动截取；**严禁自行启动/点击游戏**

## 七、翻译口径速查

- 装备/武器**型号保留原文**（M4A1、Bf-109G2）；有通行译名的著名装备译中文（谢尔曼、丘吉尔）；
  **军舰舰名与舰级保留原文**（`USS Iowa` / `Admiral Hipper` / `Sanyo Maru`）
- 各国原语言兵种/编制/后勤名译中文（Pioneeri→工兵）；**大写缩写保留**（`AT` `FlaK` `BB` `ZOC` `LOS` `VH` `AAR`）
- **方括号/花括号标记**（`[XIII]` `[DAF]` `{Sab}`）视为符号保留
- **立场原则**：按扮演方视角用其自己的作战代号与编制名。禁用蔑称旧称
- 日期 `1941年5月14日`（无空格）；知名将领用通行译名
- **单位级别**：纯「数字+兵种缩写」位于父位 = **师级**（`N Pz`→第N装甲师）；
  后接 `R/Bde/Rgt/Bn` = 团/旅级。判据＝番号串顺序是 `本单位/上级/再上级`
- **括号全/半角是分层约定**：场景 `.txt` 用**全角**；`equip.txt`/`.xscn` 用**半角**
- ⚠️ **改专名前必须先查同一 efile 的既有对译**（AG 的 `praetor` 既有译法是「法官」而非「裁判官」）
