## 一、结论摘要

**可行性判定：可行，且比前作 PeG 更好做。属于「同引擎同构建 + 文本全外置」型，最贵的进制层工作完全不存在。**

三条决定性证据：

1. ⭐ **12 个 efile 与已汉化成功的 `PeG030.exe` 是同一构建**（`TimeDateStamp` 均为 `903998521` = 1998-08-24，段布局逐字段一致），
   且三处双字节补丁落点**逐字节等于原版** ⇒ **PeG 的三开关补丁可 1:1 套用，无需重新逆向。**
2. **文本 100% 外置**：exe 只硬编码文件名 stem（`WW2Gui`/`WW2Misc`/`WW2NAME`/`WW2Tips`/`ww2-eqp`/`WW2GEN`），
   界面文字全在纯文本里 ⇒ **本地化 = 覆盖同名文本文件**，`.scn`/`.map`/`.cam` 无需回写文本。
3. **位图文字层很薄**：全库仅 25 个「全屏画面」条目，实渲染证实 `STARTSCR` 与 12 个国别 `STAxx` 画面均为**纯底图，无烘焙文字**
   （与前作一致：标签由 GDI 运行时叠加）。

**改造范围概览**（明细见 §五、§六）：

| 层 | 载体 | 规模（实测） | 难度 |
|---|---|---|---|
| L0 引擎能力 | 12 × efile `.exe` | 各 734,720 B；三开关 + 日期 LCID | **极低**（补丁 1:1） |
| L1 界面字符串 | `WW2Gui.txt` | 605 行 / 576 唯一 | 低 |
| L1 装备名 | `ww2-eqp.txt`（+ `.aux`/`.eqp` 为二进制） | 1,001 行 / 906 唯一 | 中 |

| L2 场景简报 | `SCENARIO\*.txt` · `_i.txt` · `_bv/_v/_tv/_l/_log/_tx/_t` | 1,895 + 470 + 41 文件 / 4,767 可译唯一 | **高（体量）** |
| L2 地图格名 | `<场景>_m.txt` | 689 文件 / 8,753 可译唯一 | 高 |
| L2 部队名 | `<场景>_u.txt` | 682 文件 / 10,866 可译唯一 | 高 |

## 三、字符编码与引擎三开关（治本层）

### 3.1 源文本编码（[已实测]）

| 项 | 结论 |
|---|---|
| 编码模型 | **单字节 8-bit ANSI**，无 Unicode 路径 |
| 源码页 | **cp1252**，高字节极稀少：`SCENARIO\*.txt` 16,403 行中高字节 **157 个**；`_m.txt` 58 个；`_u.txt` 14 个 |
| 界面文件 | `WW2Gui.txt` / `WW2Misc.txt` / `WW2NAME.TXT` / `WW2Tips.TXT` **高字节 = 0（纯 ASCII）** |
| 行尾 | **CRLF** 为主（`WW2Gui.txt` 604×CRLF）；`ww2-eqp.txt` 1000×CRLF |
| BOM | **全部无 BOM** |
| ⇒ 出稿口径 | 沿用前作纪律：**GBK(936) + 无 BOM + 沿用原文换行**；拆行必须 `(\r\n\|\r\|\n)` **三态** |

> ⚠️ **cp1252 假汉字陷阱在本作极小**（高字节占比 0.01%–0.4%），但判据仍用「GB2312 字节范围 + 假汉字黑名单」，不用裸 `decode('gbk')`。

### 3.2 三开关补丁落点（**文件偏移 FO 制**，与 PeG 完全一致）

| # | 用途 | FO | 原版字节 | 补丁后 | 说明 |
|---|---|---|---|---|---|
| ① | `CreateFontA` 的 `iCharSet` 立即数 | `0x70CE4` | `00` | **`86`** | GB2312_CHARSET(134) |
| ② | `_pctype` 字符类别表高字节区 | `0xA938A`–`0xA9489`（254 B） | `00 00 ×N` | **`40 80` 交替** | 0x81–0xFE → `0x8040`（`_BLANK｜_LEADBYTE`） |
| ③ | `__mbcodepage` | `0xA948C`（2 B） | `01 00` | **`A8 03`** | 936，启用 MBCS |
| ④ | 日期 LCID（`GetDateFormatA` 入参） | `0x7BE86`（4 B） | `A1 48 91 49` | **`B8 04 08 00`** | `mov eax,0x0804`（zh-CN，等长） |
| ⑤（可选） | CRT `lc_time` 月份/星期表 | `0x8B47C`–`0x8B555` | 英文月/星期 | 中文 | 前作**实测无效**（日期不走这里），仅作无害保留；**本作建议不打**以缩小差异面 |

**核验结论（[已实测]）**：上述 ①②③④ 四处，**12 个 efile 全部逐字节等于原版 `PeG030.exe.orig-backup`**；
参照系为「已实机验证成功的 `PeG030.exe`」，其与自身原版的差异**共 382 字节**，全部落在 ①–⑤ 五段内、无其他改动 ⇒ **补丁集完整且最小**。

> ⚠️ **前作的两条旧补丁已作废**（本项目勿重蹈）：
> - `patch-lineterm.py`（行终止表 0xA938A 区）——已被 ② `_pctype` 补丁覆盖并取代；
> - `patch-labeldrop.py`（`0x46FF1C` `7C 08→EB 00`）——**最终成品 exe 里并不存在**，已撤回。
> ⇒ 本项目**只做 ①②③④**，不做任何**按字节位移/丢行**相关的改动（根因已由三开关一并解决）。

### 3.3 字体（沿用前作结论，本作待实机复核）

- `CreateFontA` 参数：`lfHeight=-12`、`FW_NORMAL`、`iCharSet=0(→134)`、`PROOF_QUALITY`、**`pszFaceName=NULL`**（系统默认字体）。
- 前作离线探针（ctypes 复刻调用、实渲染看像素）证实：**ACP=936 下中文经字体链接（font linking）正常成像，无豆腐块，无需改字体名**。
  ⚠️ 判据教训：`GetGlyphIndicesW` 报字形缺失 **≠** 画不出，必须实渲染。
- 本作 exe 与 PeG 同构建 ⇒ 预期一致，**但仍须实机截图确认**（见 §七 R1）。

## 六、位图与媒体层

### 6.1 `WW2GEN.dat`（165 MB / 9,467 个 `.s16`）

格式：`u32 nEntry + u32 dirEnd + nEntry×(13B 名 + u32 偏移)`；`.s16`：`u32 nIcons + nIcons×40B{w,h,startX,startY,fullW,fullH,starts,nbytes,comp,load}`，图形数据 `RLE = u8 重复次数 + u16 RGB565`。

- **全屏候选（≥600×400）仅 25 个**，逐一列名见 `research/evidence/recon7-fullscreen.txt`：
  `STARTSCR`（启动画面）· `STAFR/STAG2/STAGE/STAJP/STARA/STASV/STAUK/STAUS/SPAR/STPAC/STRAN/STRDA`（12 个国别画面）·
  `SCENDESC`（选场景底图）· `HEX` · `UNITINFO` · `MLTICHAT` · `TEXTBOX` · `BRIEF` · `MAINBAR` · `INFTRYR1` · `NOTFIRED` · `SBT55` · `GEN20` · `FR09` · `DUTCH` · `STARB` · `BUTTPZN`
- ✅ **实渲染取证（[已实测]）**：`STARTSCR[0]` 与 `STAGE[0]`（德国）、`STAFR[0]`（法国）、`SPAR[0]` 均为 **800×600 深色金属底图，画面内无任何文字**；
  `SCENDESC[0]` 为 800×600 世界地图线稿 + 绿色 UI 框，**亦无文字**。
  ⇒ 与前作一致：**标题/国别画面的文字由 GDI 运行时用文本文件叠加**，无需重绘。
- ⚠️ **待专项（Phase 3 可选）**：`HEX.S16` 等少数条目按原生 RLE 解得「横向噪声」，属**第三方工具转换格式**（`MAP\*.s16` 同样由 `LG_shp2s16.exe` + `SHP2S16.EXE` 从 PG2 图形转换而来）⇒ 需逐条目判格式后再判文字。

### 6.2 `MAP\*.s16`（2,321 个 / 1.05 GB）

第三方（Fred Chlanda `SHP2S16` + `LG_Shp2s16`）转换的 PG2 地形图，随机抽查解码为**纯地形底图，无文字**

### 6.3 视频 / 语音（建议不做）

`CINE\` 5 个 `.mov` · `WAVS\` 466 个 `.wav` · `DOCS\` 手册（RTF/PDF/`*.txt` 说明）。
⚠️ `DOCS\` 是安装包说明与攻略，**非游戏内文本**；按前作纪律「不全量翻译说明类文件」，**建议整目录排除**（如需可另立副产物）。

## 八、与前作 PeG 的差异对照
