## 二、四个可复用发现

### 1. `strings_efile.txt` 要按「段名 + 条目文本」复用，不能按行

AG 125 条目，OLGWW2 中文侧只有 69 条目 ⇒ 按行复用必然错位。
按段比对后：**`[terrain]` 20 项顺序完全一致**，直接沿用既有定名（开阔地/城镇/机场/林地/密灌丛…）；
`[classes]` / `[requisition]` 是古代兵种（长矛兵/弓箭手/禁卫军…），与二战 efile 完全不同，**必须独立定名**。

### 2. `Classified*` 是占位标记，不是人名 —— 一次砍掉 44% 工作量

`names.txt` 里 `Classified*` 占 **1085 行 / 2449**，但只有 **34 个唯一值**
（`Classified`、`Classified13`、`Classified1-country 45`…），是 mod 作者的模板占位。
**⇒ 保留原文**（与 OLGWW2「前 31 行测试者昵称保留原文」口径一致）。

### 3. ⭐ 中国"人名"其实是**东汉年号 / 帝名**，必须用汉字本体，不能音译

| 原文 | 实为 | 译 |
|---|---|---|
| `Yong He` / `Yuan Jia` / `Jian Ning` / `Xi Ping` | 年号 | 永和 / 元嘉 / 建宁 / 熹平 |
| `Ben Chu` / `Bei Xiang` / `Han An` / `Yang Jia` | 年号 / 地名 | 本初 / 北乡 / 汉安 / 阳嘉 |
| `Liu Hong` / `Liu Xie` / `Liu Bian` / `Liu Zhi` | 帝名 | 刘宏（灵帝）/ 刘协（献帝）/ 刘辩（少帝）/ 刘志（桓帝） |

音译会变成"勇和""元加"之类的荒唐结果。**凡遇到拼音串，先判是年号/帝名/地名再落笔。**

### 4. 皮克特父名制 `X mac Y` 要整体定名

`Drust mac Erp` → 德鲁斯特·麦克·埃尔普（`mac` = …之子）。不能按罗马三名法拆。
同类：`Brude mac Bile`、`Gartnait mac Donuel`、`Talorc mac Uuid`、`Nechtan mac Derile`。
