## 一、界面记录表（静态读出，母本实测）

表地址 `0x4A22F8`，步长 `0x24`（36 B），条数 = `word[0x4af460]`。

| 偏移 | 类型 | 含义 |
|---|---|---|
| +0x00 | u16 | flags |
| +0x02 | i16 | x |
| +0x04 | i16 | y |
| +0x06 | i16 | right |
| +0x08 | i16 | bottom |
| +0x0a / +0x0c | i16 | 附加参数 |
| +0x10 | ptr | 绘制处理器（多数 = `0x44ACDA`） |
| +0x14 / +0x18 / +0x1c / +0x20 | ptr | 命中/其它回调 |

母本 16 条记录（X = x..right，Y = y..bottom）：

| idx | 含义 | 母本 X | 母本 Y | 宽×高 |
|---|---|---|---|---|
| 0–12 | **右侧工具栏 13 个按钮**（步距 36） | 762..787 | 41+36i .. 66+36i | 26×26 |
| 13 | 左上动作/状态条 | 20..334 | 43..54 | 315×12 |
| 14 | **底栏** | 10..790 | 576..594 | 781×19 |
| 15 | **地图视口** | 0..799 | 22..571 | 800×550 |

绘制处理器 `0x44ACDA(idx)` 精确行为（本轮反汇编确认）：

```
rec = [0x4cce2c] + idx*0x24            ; 越界保护：0 <= idx < word[0x4af460]
rect = { x = rec.x,        y = rec.y-1,
         right = rec.right+1, bottom = rec.bottom+1, surface = [0x676904] }
if (word[0x4c90e0] >> 1) & 1:          ; 仅在置位时画
    idx==1 或 idx==4:
        dx = 0x2ef(751) - rec.x
        dy = 0x16(22)   - (rec.y-1)
        0x4235E5(rect, ctrl=0x663410, index=1, dx, dy)
else:
    idx==0xe -> 0x47097a(9)
```

要点：**这两个常量只服务 idx1/idx4**，且受 `[0x4c90e0]` bit1 开关控制；
`0x47E4E0` 在 `dx < 0` 时保持 `rect.left` 不动 ⇒ 记录右移只会让 `dx` 更负，
不会把内容推走，**所以本版不需要同时改 `0x2ef`**。
