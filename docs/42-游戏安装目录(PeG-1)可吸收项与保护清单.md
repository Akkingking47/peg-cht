## 六、可复算

```powershell
# 全量哈希比对（本次判据）
#   正式版 2425 文件 / PeG-1 2426 文件；只在 PeG-1 = PeG030res.exe；内容不同 = 134
$G='D:\Program Files\PeG'; $H='D:\Program Files\PeG-1'
Get-ChildItem -LiteralPath $G -Recurse -File -Force | ForEach-Object {
  $r=$_.FullName.Substring($G.Length).TrimStart('\')
  $o="$H\$r"
  if(Test-Path -LiteralPath $o){
    if((Get-FileHash -LiteralPath $_.FullName -Algorithm MD5).Hash -ne (Get-FileHash -LiteralPath $o -Algorithm MD5).Hash){ $r }
  } else { "ONLY-OFFICIAL $r" }
}
# 关键 md5 复核
(Get-FileHash 'D:\Program Files\PeG\CWGEN.dat'   -Algorithm MD5).Hash   # EB203C11… 原版
(Get-FileHash 'D:\Program Files\PeG-1\CWGEN.dat' -Algorithm MD5).Hash   # 99876F17… 荣誉榜
```

> **数据真源**：本节所有数字、md5、字节差异段数、行号与英文对照**均由当次实测得出**，未引用未经验证的记载；
> 与 `-1` 侧文档的记载**相互印证**（CWGEN.dat 两枚 md5、6 个 exe 各 261 B、108 个 Scenario 文件）。
