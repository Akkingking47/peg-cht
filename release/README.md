# PeG / PeG-WW2 汉化发布包

仓库：`https://github.com/Akkingking47/peg-cht`

本目录存放可直接使用的汉化包。仓库本身保留工作流（脚本、词库、审计），**成品包按大小分流**：
小包随仓库提交，大包走 GitHub Release 资产。

## 文件

| 文件 | 大小 | 用途 |
|---|---|---|
| `PeG-汉化包-20261021.zip` | 0.6 MB | PeG 成品：中文 exe + 根级文本 + Scenario/Userscen 文本 + 8 个 .scn 标志；**随仓库提交** |
| `PeG-WW2-汉化包-精简版-20261021.zip` | 4.5 MB | PeG-WW2 文本 + 12 个中文 exe，不含旗帜；**随仓库提交** |
| `PeG-WW2-汉化包-完整版-20261021.zip` | 77.7 MB | 精简版 + `WW2GEN.dat`（史实德国旗）；**作为 Release 资产上传** |

## 安装

1. 备份原版游戏目录（整份复制）。
2. 将压缩包内容按目录结构覆盖到对应游戏根目录：
   - PeG → `D:\Program Files\PeG\`
   - PeG-WW2 → `D:\Program Files\PeG-WW2\`
3. 直接启动对应 exe。

包内附 `安装说明.txt` 与 `文件清单.txt`；解压后即可游玩，无需运行任何脚本。

## 说明

- 只覆盖界面/场景文本、已打中文补丁的 exe，以及可选的 `WW2GEN.dat`；
  不改 `MAP`/`SCN`/`CAM` 等地图与战役主体（PeG 另有 8 个 `.scn` 各 1 字节的简报位置标志）。
- 完整版超过 GitHub 单文件 50 MB 的建议阈值（仍低于 100 MB 硬限），故走 Release 资产。
- 还原：用备份的原版目录覆盖回来即可。
- 包内含游戏 exe 与数据文件，公开分发前请确认原游戏/MOD 授权；本项目仅供学习研究。
