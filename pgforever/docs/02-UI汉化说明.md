## 三、目录与脚本

```
pgforever\
  ├─ backup\origin\            ← 不可变快照（Default\UI + 12 个 game\UI + PG\Scenario + PGForever.exe）
  ├─ docs\
  │    ├─ 01-POC报告.md        ← 编码与渲染验证
  │    └─ 02-UI汉化说明.md     ← 本文件
  ├─ work\ui\
  │    ├─ strings.json         ← 提取的条目（含行号，便于定位）
  │    ├─ translations.json    ← 翻译表（global + per_file 覆盖）
  │    └─ missing.json         ← 未译条目（当前为空）
  ├─ tools\
  │    ├─ extract_ui.py        ← 从 backup 提取待译条目
  │    ├─ ui_scan.py           ← 扫描全部 UI，找出未纳入译表的串
  │    ├─ apply_ui.py          ← 回填：backup 原文 + 译表 -> UTF-8 BOM 输出到游戏
  │    ├─ verify_dialogs.py    ← 换位渲染验证（无需输入）
  │    ├─ tour.py / drive.py / shot.py / crop.py / locate.py / enumwin.py  ← 截屏、定位、诊断工具
  └─ poc\                      ← 全部验证截图
```

### 修改流程（后续维护）

1. 改 `work\ui\translations.json`（`global` 通用；`per_file` 覆盖同词不同义）
2. 跑 `tools\apply_ui.py` —— 自动从 backup 读原文、套用、校验、写 UTF-8 BOM
3. 需要看图验证时跑 `tools\verify_dialogs.py <文件名…>`

> **切勿直接编辑游戏目录的 htm**（编码易被编辑器改坏，且破坏可复现性）。

## 四、关键实现细节

1. **同词不同义**必须分开译：`Close` 在 `combatlog.htm` 是按钮（→关闭），
   在 `unit.htm`/`neweqp.htm`/`purchase.htm` 是类别名占位符（→近距）。译表用 `per_file` 处理。
2. **替换按 en 长度降序**，避免短串吃掉长串（如 `Def` 不会破坏 `Ground Def`）。
3. **纯字母串加词边界保护**，`of` 不会误伤 `Soft`。
4. **中文排版清理**：去掉汉字之间、以及闭合标签后多余的空格
   （英文式 `</span> 已结束` → `</span>已结束`）。
5. `%%` 是 HTMLayout 的转义写法，替换时必须原样保留（已加断言校验）。

## 六、回滚方式

UI 层为纯文件替换，回滚极简单：

```powershell
# 方法一：从不可变快照恢复（推荐）
Copy-Item 'D:\DSH\军事游戏汉化\pgforever\backup\origin\Default\UI\*' D:\PGForever1.021\Default\UI -Force -Recurse

# 方法二：按 game 恢复
Copy-Item 'D:\DSH\军事游戏汉化\pgforever\backup\origin\Cyber General\UI\*' 'D:\PGForever1.021\Cyber General\UI' -Force
```

> 注：原始文件从未被覆盖式修改以外的方式触碰——UI 层属于「就地替换」，
> 因此备份是唯一的回滚依据，**请勿删除 `backup\origin\`**。
